# papers/

Source publications for each trial notebook.

- PDFs live here when an open-access deposit exists (`trial-name-year.pdf`, verified with `file`/pypdf).
- When the paper is paywalled, a `TRIAL-SOURCE-NOTE.md` records exactly which public sources
  each number came from instead of a PDF.
- Never fabricate or "reconstruct" numbers beyond what these sources state; if a denominator
  must be reconstructed from a published percentage, say so in the notebook's provenance cell.
