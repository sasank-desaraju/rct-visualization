# papers/

Source publications for each trial notebook. This directory answers one
question: where did every number come from?

- An open-access PDF is stored directly as `trial-name-year.pdf`, verified as a
  PDF with `pypdf`.
- A paywalled paper gets a `TRIAL-SOURCE-NOTE.md` instead. The note lists every
  public source used for the notebook, so the provenance boundary is explicit.
- No notebook reconstructs a number beyond what these sources state. When a
  denominator is reconstructed from a published percentage, the notebook says so
  in its provenance cell.

See [INDEX.md](INDEX.md) for the full citation, registration, and source artifact
of each trial.
